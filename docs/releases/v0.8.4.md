# Seiza for Windows 0.8.4

This point release improves parallax framing, cropped dust maps, camera tours
and plate solving, using the published Seiza 0.33.0 fixes.

## Parallax framing and cropping

- Choose **Fill frame** or **Show whole image**. Match the output to a square,
  portrait or landscape source, with bounded previews and even export sizes.
- Draw a filmed crop on the source, or enter its coordinates, with optional
  frame-aspect locking. Cropping is non-destructive and supports undo/redo.
- Keep dust maps, WCS and editor points in source coordinates. Cropped dust
  replacement, painting, readback, export and reload stay aligned; unfilmed
  pixels are clear. Saved itineraries retain their crop context.

## Camera tours

- **Pull Back** moves toward whole-image framing while retaining the selected
  target, name, depth and timing. It resets Dolly, Zoom, Pan and Push and is undoable.
- Fit wide stops locally rather than magnifying the whole tour's opening.
  Endpoint spins are fitted through their holds; two-stop turns can use temporary
  magnification reported as **Transition zoom** without changing endpoint lenses.
- Edit Dolly and Zoom with independent sliders, readouts, tooltips and resets.
  Stop Zoom allows values below 1×; valid imported values remain representable.
- New custom points start at Dolly 0 / Zoom 1. Adding, duplicating, reordering
  or removing stops keeps selection and the preview playhead synchronized.
- Existing authored tours retain their original centering unless opted into
  whole-image pull-back; the setting round-trips in saved tours.

## Solving and updates

- Try original FITS/XISF astrometric headers before private snapshots and retain
  solve provenance. A header solution with no confirming stars is marked unverified.
- Reuse viewer solves made after opening the video editor and share recovered
  solutions back to the same document. Solve cancellation and a bounded search
  keep native ownership safe until the operation returns.
- Imported layers default to aligned and preserve an explicit alignment choice.
  Known starless sources solve the aligned Stars layer directly; missing or
  unaligned Stars are explained instead of attempting the starless image.
- Check the signed update feed at `https://updates.seiza.fyi/windows/appcast.xml`;
  installation signatures and the existing public trust key are unchanged.

## Dependencies and validation

Published Seiza/C ABI **0.33.0**, parallax **0.10.0**, stacking **0.36.0** and
image-io **0.8.0** include upstream fixes #277 and #283, without vendored patches.

Validation includes 679 managed tests, 78 Windows tests, actual native editor
checks, processed FITS/XISF solve fixtures, cropped dust-map round trips and nine
short Windows H.264 exports with independent decode/preview comparison. Optional
external-corpus/FFmpeg tests remain opt-in. Source images and settings were not
changed. Full-length 4K exports and an in-place upgrade of the user's live
installation are not part of that local validation.

The x64 MSI is signed as **StackFoundry LLC**. Native H.264 is available through
Windows; HEVC needs an installed Windows encoder, while MOV/MKV need optional
FFmpeg. The MSI, signed appcast and SHA-256 checksums are release assets.
