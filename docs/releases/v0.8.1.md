# Seiza for Windows 0.8.1

Align separate filter stacks to one common grid and control dust extinction
in parallax videos. This release uses published Seiza/C ABI 0.27.0,
stacking 0.29.0 and parallax 0.4.0 crates, with no vendored renderer or
unreleased dependency overrides.

[Download the Windows x64 installer](https://github.com/theatrus/seiza-win/releases/download/v0.8.1/seiza-0.8.1-windows-x86_64.msi)
· [SHA-256 checksums](https://github.com/theatrus/seiza-win/releases/download/v0.8.1/SHA256SUMS.txt)

## Shared-reference stacking

- **Stack Images** can use a shared alignment reference so separate filter
  outputs have matching dimensions and WCS. Choose an image explicitly or
  use the first stack's reference. Each filter retains its own reference for
  brightness normalization, noise weighting and calibration matching.
- Automatic reference selection tries up to five candidates in the native
  core's ranking order when the first cannot align. Skipped candidates and
  their reasons are reported; manual selection never silently falls back.
- **Live Stack** supports a separate alignment image and preserves the saved
  grid when resuming. The alignment image is excluded from folder monitoring
  and is not counted as a light unless explicitly selected as one.
- Stacking outputs protect every group's source lights, calibration masters,
  alignment images and live recovery checkpoints from replacement, including
  through file aliases and atomic export staging.

## Parallax dust maps and fixes

- Choose, reload or reset an image-based dust map. White means opaque and
  black means clear; PNG, JPEG, TIFF, FITS and XISF inputs are supported.
  Changing a map reuses the prepared scene and preserves current camera edits.
- Export dust maps as 16-bit PNG/TIFF or 32-bit FITS/XISF for editing and reuse.
  Original sources, imported layers and the active map are protected from
  overwrite. Failed or canceled exports preserve an existing destination.
- Fixed immediate dust-map changes losing pending camera edits. Export jobs
  are tracked through cancellation and workspace closure, keeping private
  scene inputs alive until background work finishes.

See the [stacking integration guide](https://github.com/theatrus/seiza-win/blob/v0.8.1/docs/STACKING-UPSTREAM.md)
and [parallax workflow and safety guide](https://github.com/theatrus/seiza-win/blob/v0.8.1/docs/PARALLAX-VIDEO.md)
for details.

## Distribution

The self-contained Windows x64 MSI and first-party application binaries are
Authenticode signed by **StackFoundry LLC**. The in-app updater verifies the
signed update feed and installer. Windows 11 24H2 or newer is required.
