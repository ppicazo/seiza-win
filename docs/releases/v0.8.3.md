# Seiza for Windows 0.8.3

Review and stack a whole capture tree with nested folder browsing, collapsible
sidebar groups and keyboard navigation that follows the grouped order.

## Nested folders and grouping

- **Open folder** includes supported images from nested subfolders by default.
  Turn **Include subfolders** off to review only the selected root folder.
- Group the sidebar by **Folder Path**, **Filter**, **File type**, or **None**.
  Relative paths and natural sorting keep capture sessions understandable,
  including files with the same name in different folders.
- Collapse and expand groups without closing the open image. Group headers
  remain keyboard-focusable, even when every group is collapsed.
- Left/Right and Previous/Next traverse every image in the complete grouped
  order, automatically expanding the destination group and revealing its card.
  Thumbnail prefetch follows the same order.
- Changing grouping or reopening the sidebar reveals the selected image
  without reloading it. Changing folder scope keeps an unchanged current
  document, its solve, overlays and viewport intact.
- Directory scans are cancellable. Unreadable subfolders and descendant
  directory links are skipped and counted rather than blocking the viewer or
  recursively following junctions.

## Stack across the opened tree

**Stack** offers FITS/XISF frames from the entire opened folder tree, regardless
of sidebar grouping or collapsed groups. The stacking dialog still lets you
choose which frames to include. Relative paths distinguish same-named files
in both the frame and reference lists. Turning **Include subfolders** off limits
the candidates to the root folder.

## Scope and compatibility

- Filter grouping uses the existing stacker's filename detection, not FITS or
  XISF headers. Unrecognized filters appear under **Other**.
- Grouping choices are per-window and are not saved between launches.
- Opening a single file still discovers its top-level siblings, not the whole
  folder tree. Hidden and system images are not excluded from folder scans.
- Native dependencies are unchanged: published Seiza/C ABI 0.30.1, stacking
  0.32.0, parallax 0.7.0 and image-io 0.5.0, without vendored patches.

## Distribution

The self-contained Windows x64 MSI and first-party application binaries are
Authenticode signed by **StackFoundry LLC**. The in-app updater verifies the
signed update feed and installer. Windows 11 24H2 or newer is required.
