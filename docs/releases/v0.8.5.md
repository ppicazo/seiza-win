# Seiza for Windows 0.8.5

This release adds multi-filter live sessions, flat-quality review and RGB/LRGB
composition, using the published Seiza 0.39.0 APIs.

## Multi-filter live sessions

- Point Live Stack at a parent **LIGHT** folder to discover L, R, G, B and other
  filters in its subfolders. Each filter has its own accumulator, reference,
  progress and resumable checkpoint; newly arriving filters are discovered too.
- See every filter's bounded preview, accepted/rejected/skipped counts and status
  in **All filters**, or select a tile for the detailed preview and SNR view.
- Switch among **Auto MTF**, **Median Anchor** and **Layered** previews, including
  while paused. Changing the display stretch leaves integrated linear pixels
  unchanged, and Layered defaults work with monochrome data.
- A calibration failure or cancelled review affects its filter without stopping
  the others. Closing saves the session's groups, including the unselected ones.
- Completion is recorded durably before retiring a checkpoint. Saving protects
  capture files, calibration masters and checkpoints across the whole session,
  including file aliases.

## Flat quality and sensor defects

- Optionally measure and screen selected raw flats before directory or live
  stacking, even when calibration masters are cached. Review illumination,
  clipping, dust, vignetting and available optical geometry measurements.
- Inspect detailed warnings and predictions, copy the complete report, and
  explicitly continue or cancel before processing lights. Predictions about a
  master are shown separately from measurements of an actual built master.
- Learn fixed sensor defects from at least three compatible dithered raw lights
  when no master dark is selected. Live checkpoints retain the fixed learned
  map, and resumed stacks keep the same correction.

## Color composition

- Combine saved, aligned linear channels into RGB or LRGB. Inputs must share an
  alignment grid; confirm this before composing them.
- Optionally verify the solve and apply Gaia color calibration, with an explicit
  catalog-download action when photometry data is needed.
- Preserve source files and existing destinations on failure. Calibrated output
  retains its WCS and calibration marker, and previews and exports preserve its
  channel balance.

## Settings and processing

- Save the **RC-Astro CLI** location under **Settings > External tools** and reuse
  it across Parallax windows and app restarts. Changes wait until active work
  finishes before replacing the executable used by a session.
- Use the new Median Anchor and Layered stretch controls in image processing.
- Remember the browser's folder/filter/file-type grouping between launches.
- Build required native DLLs explicitly before managed tests and verify their
  presence, fixing the clean-runner omission that previously broke CI.

## Dependencies and validation

Published Seiza/C ABI **0.39.0**, stacking **0.42.0**, parallax **0.16.0**,
image-io **0.9.0** and stretch **0.3.1** provide the native behavior. Dependency
versions are independent of the Windows application version.

Feature validation includes **739 managed tests**, **78 Windows tests** and the
native Rust suites; four optional Windows tests require external inputs. CI
also builds the all-users x64 MSI, verifies the Finish action and smoke-tests
installation, launch and removal. An interactive upgrade of the user's existing
installation is not part of local validation.

The production workflow Authenticode-signs the application and MSI as
**StackFoundry LLC**, signs the updater feed, and publishes the MSI, appcast,
detached appcast signature and SHA-256 checksums.
