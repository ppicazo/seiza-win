# Seiza for Windows 0.8.2

Build richer parallax tours with depth planes, painted dust, artwork and more
export formats. This release uses published Seiza/C ABI 0.30.1, stacking 0.32.0,
parallax 0.7.0 and image-io 0.5.0 crates, with no vendored renderer or unreleased
dependency overrides.

[Download the Windows x64 installer](https://github.com/theatrus/seiza-win/releases/download/v0.8.2/seiza-0.8.2-windows-x86_64.msi)
· [SHA-256 checksums](https://github.com/theatrus/seiza-win/releases/download/v0.8.2/SHA256SUMS.txt)

## Depth and camera tours

- Automatic depth planes separate catalogued nebulae and foreground dust.
  Inspect each plane and override an object's distance, or add your own
  image-mask plane with a name and distance.
- Generate editable tours on the prepared scene, using the planes actually
  shown at each destination without moving the scene's distance reference.
  Give individual stops an explicit target depth when needed. Imported tour
  files retain authored depths; moving a destination clears its old override.
- The updated renderer keeps related nebulae together and reduces camera
  travel when a move would expose too much filled background. Reported fit
  adjustments include those dolly reductions.
- Plane-inspector metadata now refreshes even when plane names stay the same.

## Dust, artwork and portable itineraries

- Paint or clear a dust map with soft brushes, undo/redo and reset. Apply keeps
  a private 16-bit snapshot across scene preparation; Cancel keeps the existing
  map. Export the current or counted opacity map for reuse.
- Add a credit logo with size, corner and opacity controls, plus opening,
  closing and per-stop title-card images.
- Itinerary card paths resolve beside the tour file. Saving uses portable
  relative references for in-folder artwork without changing the open draft.
- Export protects original images, layers, artwork, masks and previously
  selected maps, even after replacing inputs. Cancellation and failed jobs
  preserve existing output files.

## More export choices

- Keep native Windows H.264/HEVC MP4, or export a lossless PNG frame sequence
  into a new folder.
- MOV and MKV are available through an optional existing FFmpeg installation
  or selected executable. Seiza does not bundle or download FFmpeg. Encoder
  availability determines H.264/HEVC support.
- Existing sequence folders are never merged into or replaced. Frame export
  is bounded, cancellation is tracked, and temporary output is cleaned up.

The FITS/XISF shell reader dependencies are refreshed, including compatibility
with the newer XML parser. The README now leads with features, native editor
screenshots and linked landscape/portrait video examples.

## Known limitations

- Short looping videos can show an abrupt transition when opening and closing
  title cards overlap.
- Windows may report an MKV's frame rate as half its actual rate; the generated
  file retains the selected timing. MP4/MOV do not show this metadata issue.
- Native HEVC MP4 requires an available Windows encoder. Optional FFmpeg
  export has separate encoder requirements.
